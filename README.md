# Welcome to Vision Lumina Player

Vision Lumina Player — это современный десктопный видеоплеер, построенный на основе Electron и HTML5 Video. Приложение предоставляет полноценный интерфейс для управления видеобиблиотекой, поддерживает воспроизведение локальных файлов, совместный просмотр через P2P-комнаты и расширенные настройки воспроизведения.

**Актуальная версия:** `2.6.0`

## 🚀 Ключевые возможности:

- **Универсальное воспроизведение**: Поддержка видеофайлов `mp4`, `avi`, `mkv`, `mov`, `wmv`, `webm` и других форматов.
- **Домашняя библиотека**: Удобное управление коллекцией, недавние файлы, избранное и плейлисты.
- **Статистика просмотров**: Автоматический подсчёт времени просмотра, сессий, серий дней подряд и топ-10 самых просматриваемых файлов.
- **Watch Together**: Совместный просмотр через P2P-комнаты на WebSocket с синхронизацией play / pause / seek.
- **Stable Volume**: Автоматическое выравнивание громкости через Web Audio API / DynamicsCompressor.
- **Ambient Mode**: Мягкая фоновая подсветка, повторяющая цвета видео.
- **Zoom & Pan**: Масштабирование кадра колесом мыши и панорамирование при увеличении.
- **Субтитры**: Загрузка и отображение файлов `.srt` и `.vtt`.
- **Drag & Drop и ассоциации файлов**: Быстрое открытие видео перетаскиванием, из проводника или командной строки.

## 🔧 Технологический стек

- **Frontend:** HTML5 + CSS3 + Vanilla JavaScript
- **Desktop Wrapper:** Electron 38
- **WebSocket:** `ws` (Node.js)
- **Audio Processing:** Web Audio API
- **Build & Distribution:** electron-builder
- **Localization:** Custom i18n (EN / RU)

## 🛠 Установка и запуск

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm start
```

### Сборка

```bash
npm run build-win    # Windows (NSIS)
npm run build-mac    # macOS (DMG)
npm run build-linux  # Linux (AppImage)
```

Готовые установщики сохраняются в папку `dist/`.
